# Website Pages And User Flow

## Main Pages

### Home And Shopping Page

The first screen should immediately show the shopping experience, not just a marketing hero. It should include:

- Search bar.
- Delivery location or delivery promise.
- Category navigation.
- Featured grocery products.
- Cart access.
- Current deals or savings.

### Product Listing Area

Customers should be able to browse products by:

- Fresh produce.
- Dairy and eggs.
- Bakery.
- Pantry.
- Beverages.
- Frozen foods.
- Household essentials.
- Organic picks.

### Product Details

Each product should show:

- Product name.
- Price.
- Unit size.
- Category.
- Rating or popularity signal.
- Availability.
- Add to cart button.
- Optional tags such as organic, local, bestseller, or express delivery.

### Cart

The cart should include:

- Product quantity controls.
- Item subtotal.
- Delivery fee.
- Savings.
- Estimated total.
- Suggested add-ons.
- Checkout button.

### Checkout Preview

For the first version, checkout can be a polished front-end flow with:

- Customer details.
- Delivery address.
- Delivery slot.
- Payment method placeholder.
- Order summary.
- Confirmation state.

### About Or Trust Section

This should support credibility without becoming the main experience:

- Freshness guarantee.
- Delivery standards.
- Local supplier message.
- Customer support promise.

### Contact Or Support

Include:

- Contact form placeholder.
- Support email placeholder.
- Delivery area information.
- FAQ items.

## Admin Panel Pages

### Admin Dashboard

The admin dashboard should give the business team a fast overview of store operations.

It should show:

- Today's orders.
- Today's revenue.
- Pending deliveries.
- Low-stock products.
- Open support chats.
- Top-selling products.
- Recent orders.

### Products

The products page should let admins manage the grocery catalog.

It should support:

- Add product.
- Edit product.
- Upload product image.
- Set price and discount.
- Set stock.
- Assign category.
- Add badges such as organic, local, express, or bestseller.
- Activate or deactivate products.

### Orders

The orders page should help staff process customer orders.

It should support:

- View all orders.
- Filter by pending, packed, out for delivery, delivered, and cancelled.
- Open order details.
- Update order status.
- Assign delivery slot.
- Review payment and customer information.

### Inventory

The inventory page should help staff keep products available.

It should show:

- Current stock.
- Low-stock alerts.
- Out-of-stock items.
- Inventory changes.
- Quick stock update controls.

### Customers

The customers page should show customer profiles and buying history.

It should include:

- Customer list.
- Order history.
- Contact details.
- Support conversations.
- Loyalty or subscription status later.

### Coupons And Offers

The coupons page should let admins manage promotions.

It should support:

- Create coupon.
- Set discount type.
- Set usage limits.
- Set expiry date.
- Activate or pause offers.

### Delivery Slots

The delivery slots page should let admins manage fulfillment windows.

It should support:

- Create delivery slots.
- Set delivery capacity.
- Pause unavailable slots.
- Manage same-day delivery settings.

### Support Inbox

The support inbox should let staff communicate with customers in real time.

It should include:

- Conversation list.
- Live chat thread.
- Customer and order details panel.
- Open, pending, and resolved filters.
- Agent assignment.
- Unread message badges.
- Quick replies.

### Settings

The settings page should contain business and operational configuration.

It should include:

- Store profile.
- Delivery rules.
- Tax settings.
- Payment settings.
- Support settings.
- Staff roles and permissions.

## Primary User Flow

1. Customer lands on the website.
2. Customer searches or selects a category.
3. Customer adds products to cart.
4. Customer adjusts quantities.
5. Customer selects a delivery slot.
6. Customer reviews total.
7. Customer continues to checkout.
8. Customer sees a confirmation state.

## Primary Admin Flow

1. Admin logs in.
2. Admin reviews dashboard alerts.
3. Admin checks pending orders.
4. Admin updates order status.
5. Admin reviews low-stock products.
6. Admin responds to open support chats.
7. Admin updates products, offers, or delivery slots when needed.
