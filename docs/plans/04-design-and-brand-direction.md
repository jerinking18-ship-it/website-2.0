# Design And Brand Direction

## Design Goal

The website should feel premium, fresh, fast, and trustworthy. It should look suitable for a serious client presentation, not like a basic template.

## Visual Direction

Use a Zomato-inspired grocery delivery interface with strong product browsing, bold red accents, app-like navigation, premium cards, and fast location/search-first shopping.

The design should be inspired by the polish of Zomato and other premium delivery apps, but it should not copy Zomato's exact brand, logo, content, or protected assets.

## Suggested Palette

- Delivery red as the main brand and action color.
- Crisp white for cards, drawers, and primary surfaces.
- Warm off-white for page backgrounds.
- Charcoal for readable text.
- Fresh green for stock, freshness, success, and delivered states.
- Citrus yellow for deals, savings, and free delivery progress.
- Amber for warnings and low-stock alerts.

## Typography

Use a modern sans-serif type system with:

- Strong headings.
- Readable body text.
- Clear product names.
- Compact cart and product metadata.

## Layout Principles

- Shopping controls should appear early.
- Location and search should dominate the first screen.
- Product cards should be easy to scan.
- Cart should stay accessible.
- Use app-like horizontal sections for categories, offers, essentials, and popular products.
- Use clean sections rather than oversized marketing blocks.
- Avoid decorative clutter.
- Avoid green-heavy grocery template styling.

## Visual Assets

The site should use high-quality grocery imagery, especially for:

- Hero produce scene.
- Product or category visuals.
- Freshness and delivery trust sections.

## Interaction Style

- Buttons should feel responsive and confident.
- Cart updates should be immediate.
- Filters should not reload the page.
- Checkout steps should feel simple and guided.

## Customer Website UI Direction

The customer website should feel like a premium grocery version of a Zomato-style delivery app: bold, fast, red-led, location-aware, and easy to shop.

Recommended layout:

- Sticky app-like header with logo, delivery location, search, account, and cart.
- Product-focused first screen.
- Horizontal category and offer rails.
- Product grid with quick add controls.
- Sticky desktop cart panel.
- Mobile bottom cart drawer.
- Floating support chatbox.
- Clean checkout steps.
- Premium live tracking card inspired by food delivery apps.

Product cards should include:

- Product image.
- Product badge.
- Product name.
- Unit size.
- Price and discount.
- Rating or freshness signal.
- Add button.
- Quantity stepper after adding.
- Delivery time or express label.
- Discount and savings treatment.

## Admin Panel UI Direction

The admin panel should feel operational, clear, and fast. It should be less decorative than the customer site and designed for repeated daily use.

Recommended layout:

- Left sidebar navigation.
- Top bar with search, notifications, and admin profile.
- Main dashboard content area.
- Tables for operational data.
- Filters and status tabs.
- Drawers or modals for add/edit forms.
- Status badges for orders, stock, payments, and support.

Admin panel style:

- Compact spacing.
- Clear data hierarchy.
- Strong table readability.
- Calm neutral background.
- Use brand red for primary actions.
- Use red, amber, blue, and green only for meaningful statuses.

Important admin screens:

- Dashboard.
- Products.
- Orders.
- Inventory.
- Customers.
- Coupons and offers.
- Delivery slots.
- Support inbox.
- Settings.

## Accessibility Direction

- Text should be readable on mobile and desktop.
- Buttons should have clear labels.
- Keyboard navigation should work for interactive controls.
- Color should not be the only way to understand status.
