# Coupons And Promotions Plan

## Goal

The Coupons and Promotions admin module should become a marketing campaign control center for grocery growth, discount governance, banner management, campaign scheduling, and coupon risk monitoring.

## 1. Overview Stats

- Active coupons
- Total redemptions
- Revenue from campaigns
- Discount cost
- Conversion rate
- Expiring soon
- Failed coupon attempts

## 2. Coupon Management

Each coupon should show:

- Coupon code such as `FRESH20`, `WELCOME100`, or `DAIRY50`
- Discount type: percentage, flat amount, free delivery
- Minimum cart value
- Maximum discount cap
- Usage limit
- Per-user limit
- Valid start and end dates
- Status: Active, Scheduled, Expired, or Paused
- Target segment: new users, VIP, COD users, inactive users, repeat buyers
- Quick actions: Edit, Pause, Duplicate, View usage

## 3. Promotion Banners

Admin should manage:

- Homepage banner
- Category banner
- Product detail banner
- Cart banner
- Checkout banner
- Footer promotion banner

Each banner should have:

- Title
- Subtitle
- CTA text
- Image
- Target URL
- Start and end date
- Audience segment
- Priority/order
- Status

## 4. Campaign Segments

Useful campaign filters:

- New customers
- Repeat buyers
- VIP customers
- Inactive customers
- High cart value users
- Category-specific buyers
- Location or delivery-zone based users
- First order users

## 5. Coupon Rules

Useful rules:

- First order only
- Minimum cart value
- Specific category or product
- Specific payment method
- Delivery slot based
- Location based
- COD or online only
- New customer only
- Stackable or not stackable

## 6. Performance Analytics

Show:

- Coupon usage trend
- Revenue generated
- Average order value after coupon
- Discount leakage
- Most used coupons
- Best converting campaign
- Low-performing coupons

## 7. Create Coupon Form

Fields:

- Coupon code
- Campaign name
- Discount type
- Discount value
- Minimum cart value
- Maximum discount cap
- Start/end date
- Usage limit
- Customer segment
- Applicable categories/products
- Status

## 8. Promotion Calendar

Track:

- Scheduled campaigns
- Festival offers
- Weekend offers
- Flash sale
- Payday sale
- Category-specific campaigns

## 9. Abuse And Risk

Show:

- Repeated failed coupon attempts
- Same address using multiple accounts
- High discount users
- Suspicious redemptions
- Coupons exceeding budget

## 10. Grocery-Specific Promotions

Add:

- Fresh produce deals
- Dairy morning offers
- Weekly grocery basket discounts
- Free delivery over cart value
- Organic category offers
- Repeat basket coupons
- Subscription and loyalty coupons

## Recommended UI Direction

Build this module as a Marketing Campaign Center with:

- Top performance stats
- Coupon table
- Banner manager
- Segment and rule controls
- Create coupon modal
- Campaign calendar
- Abuse and risk panel
