# FreshCart Market

Production-grade grocery ecommerce platform planned as a modular monorepo.

## Workspace

- `apps/web`: customer grocery website
- `apps/admin`: admin panel
- `apps/api`: NestJS CQRS backend
- `packages/ui`: shared UI components
- `packages/types`: shared TypeScript types
- `packages/config`: shared tooling config
- `packages/utils`: shared utilities

## Planning

Project planning lives in `docs/plans`. The central guide is `codex.md`, and current project memory is in `memory.md`.
