# Planning

## Admin Customers CRM Plan

The Customers page in the admin panel should become a customer CRM, not a placeholder. It should help store owners understand buying behavior, customer value, loyalty, risk, and support needs.

### 1. Customer Overview Cards

- Total customers
- New customers today
- Repeat customers
- VIP or high-value customers
- Customers with active carts
- Customers with support issues

### 2. Customer List

Each customer row should show:

- Customer name
- Phone or email
- Last order date
- Total orders
- Total spend
- Average order value
- Loyalty tier
- Status such as Active, New, At risk, or Blocked
- Quick actions: View, Message, Orders

### 3. Customer Profile Panel

When an admin opens a customer, the profile area should show:

- Basic customer details
- Saved addresses
- Recent orders
- Wishlist items
- Active cart items
- Support tickets
- Payment preference
- Delivery instructions
- Refund history

### 4. Customer Segments

Useful filters:

- New customers
- Repeat buyers
- High spenders
- Inactive customers
- COD users
- Coupon users
- Subscription customers
- Customers with complaints

### 5. Loyalty And Rewards

Track:

- Loyalty points
- Wallet balance
- Referral code
- Reward tier
- Cashback history
- Coupon eligibility

### 6. Communication

Admin should be able to:

- Send WhatsApp
- Send SMS
- Send email
- Send push notification
- Add an internal note

### 7. Risk And Support

Admin should see:

- Repeated refunds
- Failed payments
- Too many cancellations
- Open support tickets
- Fraud or risk flag
- Block or unblock customer action

### 8. Grocery-Specific Data

Important grocery-specific customer data:

- Favorite categories
- Frequently bought items
- Preferred delivery slot
- Preferred address
- Monthly grocery spend
- Organic/local preference
- Subscription or repeat basket

### Recommended UI Direction

Build the Customers page as a premium CRM screen with:

- Stats at the top
- Segment filters
- Customer list/table
- Right-side customer profile panel
- Communication buttons
- Loyalty and risk sections

This should make the page feel like a real 2026 grocery ecommerce admin module.
