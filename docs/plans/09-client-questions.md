# Client Questions

Use these questions before final development or before replacing placeholder content.

## Brand

1. What is the final business name?
2. Do you already have a logo?
3. Do you have brand colors?
4. Should the website feel premium, budget-friendly, organic, local, or family-focused?

## Products

1. How many products should be listed at launch?
2. What are the main grocery categories?
3. Do you have product photos?
4. Do prices include taxes?
5. Should discounts and offers be shown?

## Delivery

1. Which cities or areas do you deliver to?
2. What are the delivery charges?
3. Is there free delivery above a certain cart amount?
4. What delivery slots are available?
5. Do you support same-day delivery?

## Checkout

1. Should the first version include real payments?
2. Which payment methods do you want?
3. Do you support cash on delivery?
4. Do customers need accounts to order?

## Business Operations

1. Who will update products and prices?
2. Do you need an admin dashboard?
3. Do you need inventory tracking?
4. Do you need order notifications by email, WhatsApp, or SMS?

## Admin Panel

1. Which staff members will use the admin panel?
2. What roles are needed: owner, manager, support agent, inventory staff, delivery staff?
3. Should admins be able to add and edit products?
4. Should admins be able to update order status?
5. Should admins be able to create coupons and offers?
6. Should admins be able to manage delivery slots?
7. Should admin activity be logged for security?
8. Should the admin panel be available on mobile?

## Customer Support

1. Should customers be able to chat before placing an order?
2. Should customers be able to chat about existing orders?
3. How many support agents will use the admin inbox?
4. Should conversations be assigned manually or automatically?
5. Should support messages trigger email, WhatsApp, or SMS notifications?
6. Should the chatbox support attachments such as order screenshots or product photos?

## Technical Architecture

1. Do you want the full production build to use CQRS from the start?
2. Should we use PostgreSQL as the main database?
3. Should the support chat be real-time with WebSockets?
4. Should the first version include an admin support inbox?
5. Should product search use Meilisearch or a simpler PostgreSQL search first?
6. Should the admin panel be a separate app or part of the same Next.js app at first?

## Launch

1. Do you already own a domain?
2. Should the site be public immediately or private for review first?
3. What is the target launch date?
4. Who approves the final website?
