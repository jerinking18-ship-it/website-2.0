# Development Roadmap

## Phase 1: Planning

- Confirm client goals.
- Confirm brand name.
- Confirm required pages.
- Confirm product categories.
- Confirm launch timeline.

## Phase 2: First Website Build

- Create project structure.
- Build home and shopping page.
- Add product catalog.
- Add search and filters.
- Add cart behavior.
- Add delivery slot selection.
- Add checkout preview.
- Make layout responsive.

## Phase 3: Backend Architecture

- Set up NestJS backend.
- Add CQRS structure.
- Add PostgreSQL and Prisma.
- Create product module.
- Create cart module.
- Create order module.
- Create checkout module.
- Add Redis for cache, queues, and realtime support.

## Phase 4: Customer Support Chat

- Add customer chatbox UI.
- Add NestJS WebSocket Gateway.
- Store conversations and messages.
- Add typing indicators.
- Add unread message counts.
- Add conversation history.

## Phase 5: Admin Support Inbox

- Build admin support inbox.
- Add open, pending, and resolved filters.
- Add support agent assignment.
- Add real-time replies.
- Add conversation search.
- Add resolved conversation workflow.

## Phase 6: Admin Panel

- Build admin layout with sidebar and top bar.
- Build admin dashboard.
- Build product management.
- Build order management.
- Build inventory management.
- Build customer management.
- Build coupons and offers.
- Build delivery slot management.
- Build settings.
- Add role-based access control.

## Phase 7: Polish

- Improve product card design.
- Add final imagery.
- Refine mobile experience.
- Add animations and interaction states.
- Improve copy and trust messaging.

## Phase 8: Client Review

- Share preview link.
- Collect feedback.
- Update brand details.
- Update products and prices.
- Fix content issues.

## Phase 9: Deployment

- Build production version.
- Deploy private preview.
- Connect custom domain if requested.
- Prepare handoff notes.
